# JF Decor Cortinas — prévia conceitual

Abra `index.html` para ver a vitrine e `arte/prancha.html` para a apresentação em notebook, tablet e celular. O projeto é estático e não precisa de instalação.

O catálogo contém dez referências únicas. Quatro usam fotografias do catálogo compartilhado pela equipe; os demais cartões são tipográficos para não sugerir fotos de produtos que ainda não foram recebidas. Só o item que mostra preço no catálogo apresenta valor, com aviso de confirmação.

Consulte `BRIEF.md` para fatos e pendências e `ASSET_CREDITS.md` para a origem das imagens.
